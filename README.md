# MIRROR

A narrative-driven Game Boy game about confronting parallel versions of yourself.

## About

You're running late for school and take a shortcut through Hawk Forest. You fall into a parallel universe where you encounter three versions of yourself: a lonely child, a regretful old man, and an evil counterpart trying to escape. Through these encounters, you learn to accept all parts of yourself.

**Theme:** Reflection  
**Playtime:** 5-10 minutes  
**Platform:** Game Boy / Game Boy Color  
**Development Time:** ~4-6 hours

## Built With

- [GB Studio](https://www.gbstudio.dev/) - Game Boy game creation tool
- Pokemon FireRed tilesets (Nintendo/Game Freak) - for educational purposes


## Controls

- **Arrow Keys**: Move
- **Z**: Interact/Advance dialogue
